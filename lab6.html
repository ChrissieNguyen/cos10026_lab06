Headings and Paragraphs

Headings and paragraphs are BLOCK elements

Headings

There are 6 levels of heading. Headings are logical marked. Do not skip levels. If you want to change the size of a heading, don't change its level - change the CSS.

Paragraphs

Paragraphs contain the body text of a web page. You cannot put another block element inside a paragraph.

Special Characters

While HTML supports many named special characters like ® (#174), XML only supports 5 namely: " ' & < and >. So to keep you HTML compliant you need to use numbers for all the others.

Accessibility and Ethics Reflection

How can accessibility be improved for all users?

  • Use semantic HTML elements and organise headings in a logical order.
  • Provide descriptive alternative text for meaningful images.
  • Support keyboard navigation with a skip link and visible focus indicators.
  • Use sufficient colour contrast between text and backgrounds.
  • Create a responsive layout that supports small screens and enlarged text.

Are there any ethical concerns to address?

  • Users should be clearly informed when links open external websites or email applications.
  • Personal information should not be collected without a clear purpose and appropriate notice.
  • Analytics and tracking cookies should not be used without informing users.
  • Content and navigation should use clear language and avoid misleading users.

What changes make the design more inclusive and responsible?

  • Add keyboard-accessible navigation and clearly visible focus indicators.
  • Use descriptive links, image alternatives, captions and table headings.
  • Support screen readers, mobile devices and users who enlarge page content.
  • Avoid relying only on colour to communicate information.
  • Test the page using WAVE and manually check keyboard navigation.
